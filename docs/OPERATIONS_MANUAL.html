Operations Manual

What this is: A private brokerage system + 6-agent team that finds leads and prepares deals. You approve outreach, call organizers, host intros, and collect commission.

What this is NOT: A public marketplace like InviteMySponsors (no Exact Match wall — avoids Uber/Ola leakage).

Slide 1 — Business model

  • Contract with event organizers: you bring sponsors for open packages.
  • Charge 10–20% commission on each closed sponsorship.
  • Start: small events, one city/niche → build rich brand CRM → scale up.
Leakage rule: Never show organizers a browsable list of brand names + Invite buttons. You hold contacts; intros are hosted.

Slide 3 — Software modules (end-to-end)

  1. Dashboard — stats, agent runs, your tasks
  2. Events — organizer pipeline, planning stage, LOI
  3. Brands — private sponsor CRM
  4. Matches — fit scores; approve before intro
  5. Outreach — approve drafts, you send
  6. Deals — amount + auto commission
  7. Your tasks — only work that requires you
  8. CLI orchestrator — runs all agents daily

Slide 4 — Install & run (Windows)

cd sponsorship-brokerage-os
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m agents.orchestrator --seed-demo
python -m uvicorn app.main:app --reload

Open http://127.0.0.1:8000

Daily: python -m agents.orchestrator --daily

Slide 7 — Finding brands (private CRM)

  • Logos on last year’s event posters → warm leads
  • Local D2C, edtech, banks, coaching, gyms
  • Mark status: prospect → researching → active_buyer
  • Never export full list to organizers
