Honest limit — agent vs you

The agent cannot invent brands that already said “yes.” A signed / verbal yes only exists after a human call or reply. Closest to 100%: past Blithchron partners (already said yes once) — start there.

  1. Open Blithchron '27 → call/WhatsApp the renew list first (Krispy Water, CBI, Coke, Monster, Maggi, Souled Store…).
  2. Pitch line: 0 fee from brand side — you only pay the fest; our commission is from the event.
  3. When someone agrees, add a Deal (amount + %). That is real conversion in the CRM.
  4. On this page: save Gmail App Password under Outreach, tap Convert now, watch sends in the feed. Pause anytime.
  5. Phone-only leads: agent prepares copy; you 1-tap WhatsApp on Blithchron (no WA gateway yet).

What the agent is doing

  1. Pitch Writer builds Blithchron + Gujarat emails and WhatsApp copy.
  2. Closer auto-sends emails from your Gmail (up to ~12 per cycle) — no per-message ask.
  3. Follow-up after ~3 days with no reply.
  4. Every send / fail / bounce is logged below.
  5. Light scout every few cycles so the queue does not dry up.
